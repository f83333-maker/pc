旧版本

iPad/iPhone 安装旧版本 APP 的干净方法

这一方法需要配合电脑完成，核心思路是：用最后一个支持下载 App 的旧版 iTunes，配合 Fiddler 拦截并修改请求中的版本 ID，从而下载到目标版本的 .ipa 安装包，再通过工具安装到设备上。

发布日期：2025-10-23分类：旧版本

第一步：安装旧版 iTunes

需要使用 12.6.5.3 这个最后支持 App 下载的 iTunes 版本，官方下载地址如下：

64 位：https://secure-appldnld.apple.com/itunes12/091-87819-20180912-69177170-B085-11E8-B6AB-C1D03409AD2A6/iTunes64Setup.exe
32 位：https://secure-appldnld.apple.com/itunes12/091-87820-20180912-69177170-B085-11E8-B6AB-C1D03409AD2A5/iTunesSetup.exe

安装完成后打开 iTunes，点击菜单栏「账户」选项登录 Apple ID。如登录失败，可挂上代理重试；新账号需先在手机或网页登录一次以确认服务条款，否则 iTunes 因不支持显示条款会导致登录失败。

第二步：安装并配置 Fiddler

Fiddler 用于拦截并改写 iTunes 网络请求。

Fiddler 官网下载：https://www.telerik.com/download/fiddler
  1. 打开 Fiddler，点击菜单栏 Tools → Options。
  2. 在 HTTPS 选项卡下勾选「Capture HTTPS CONNECTs」与「Decrypt HTTPs traffic」，按提示安装证书。
  3. 勾选「Ignore server certificate errors (unsafe)」。

第三步：获取目标版本 ID

下载旧版本 .ipa 之前，先要拿到目标软件版本 ID。可在以下网站查询：

https://appstore.bilin.eu.org
https://app.agzy.cn

如果查询不到，可以在 iTunes 中先下载该应用，然后点击 iTunes 菜单栏「文件」→「资料库」→「打开 Genius」，切换到「应用」分类，右键你下载的项目，选择「在 Windows 资源管理器中显示」。把生成的 .ipa 文件解压，打开其中的 iTunesMetadata.plist，搜索关键字 softwareVersionExternalIdentifiers 定位到版本 ID 列表（由旧到新）。可借助七麦数据等平台对照版本号确认对应关系。

第四步：拦截并替换版本 ID 完成下载

  1. 在 iTunes 商店内进入目标应用详情页。
  2. 打开 Fiddler，左侧栏底部黑色输入框输入 bpu MZBuy.woa 回车，设置拦截断点。
  3. 回到 iTunes 点击下载，Fiddler 左侧栏会出现拦截标记的请求。点击它，在右侧 TextView 选项页找到版本 ID，替换为目标版本 ID。
  4. 点击「Run to Completion」绿色按钮，然后退出 Fiddler，iTunes 会接着下载所选版本。

第五步：取出并安装 .ipa

下载完成后，按「文件」→「资料库」→「打开 Genius」，切换到「应用」，右键下载的项目，选择「在 Windows 资源管理器中显示」即可定位到 .ipa 安装包。再借助 iMazing 之类的工具就能把它安装到 iPhone/iPad 上。
